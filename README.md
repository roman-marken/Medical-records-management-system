# MyStat — платформа онлайн-навчання

Навчальний дашборд студента на React, TypeScript, Vite та Context API. Інтерфейс повторює структуру кабінету зі скриншотів: бокова навігація, успішність, завдання, активність, рейтинг, календар і розклад.

## Запуск

```bash
npm install
npm run dev
```

Production-збірка: `npm run build`.

## Глобальний стан

- `src/contexts` містить AuthContext, ThemeContext, LanguageContext і CourseContext.
- `src/hooks` містить `useAuth`, `useTheme`, `useLanguage` і `useCourses`.
- Тема, мова та записані курси зберігаються в localStorage.
- Вхід/вихід змінює студента та статус авторизації. Для демонстрації застосунок відкривається з тестовим студентом.
- У каталозі курсів можна додавати та видаляти курси; список «Мої курси» оновлюється одразу.

Це frontend-прототип для домашнього завдання. Дані рейтингу, оцінок і розкладу демонстраційні; реальної автентифікації та серверного API немає.
